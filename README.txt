Aperture 静态源码

1. 单文件：上传根目录 index.html 即可，不需要安装、构建、Node、GPT 或 Sites。所有样式、脚本、默认收藏和 Logo 均内联。
2. 拆分版：将 split 目录里的全部文件放入 GitHub 仓库的发布目录。Settings > Pages > Deploy from a branch，选择分支和目录。所有路径使用相对路径，支持 /仓库名/ 子目录。
3. 首次迁移：原站浏览器数据不会自动跨域搬迁。先从原站导出 JSON，再到新站设置中导入。此包不包含你的私人备注、点击历史和个性化本地收藏，只包含预置网站。
4. 收藏、设置、排序和点击记录保存在 localStorage；清除浏览器数据会丢失，请定期备份。
5. 外部服务：favicon 使用 Google favicon 服务；天气使用 Open-Meteo；新闻使用 rss2json 公开 RSS 转换服务，无 GPT 依赖。服务不可用时收藏仍可用。
6. 静态网页受 CORS 限制，无法可靠检查任意外站。仅对允许跨域的响应判断状态，其余显示未确认。
7. 单文件无需其他文件即可打开，但完整 PWA 需要独立 manifest、Service Worker 和 PNG 图标，因此使用 split 版。HTTPS 部署后，支持的浏览器可安装。普通网页不能直接替换浏览器新标签页，需要浏览器设置或扩展。
8. 安全/验证：无服务端、无密钥、无包依赖。保留完整可编辑代码，未压缩。动态数据需要联网。
